# Club Sportif Sitiame

Application Frappe minimale ajoutant l'icone d'accueil "Club Sportif" sur ERPNext, reposant sur les DocTypes deja fournis par Frappe/ERPNext (Customer, Event, Subscription, Subscription Plan) sans DocType personnalise ni logique metier.

## Installation

```bash
bench get-app https://github.com/YANIXX35/sport_test_sitiame.git
bench --site <votre-site> install-app sitiame_sport
```
